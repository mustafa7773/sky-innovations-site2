# ابتكارات السماء — Sky Innovations

موقع تعريفي ثابت (HTML/CSS/JS) جاهز للنشر على GitHub Pages.

## النشر
1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع **محتويات** هذا المجلد في جذر المستودع (لا المجلد نفسه).
3. Settings → Pages → Branch: `main` / `(root)` → Save.

## البنية
- `index.html` الرئيسية · `services.html` الخدمات · `products.html` المنتجات
- `bicodi-products.html` بطاريات BICODI · `mosques-app.html` تطبيق المساجد
- `scientific-equipment.html` الأجهزة العلمية · `qibla-request.html` طلب القبلة
- `projects.html` · `majan-academy.html` · `about-us.html` · `values.html` · `contact-us.html`
- `assets/site.css` + `assets/site.js` — شريط التنقل والتذييل الموحّدان وتحسينات الوصول
- `images/` الصور · `.nojekyll` تعطيل معالجة Jekyll

## تعديل القائمة أو التذييل
موجودان في كل صفحة داخل `<nav class="sn-nav">` و`<footer class="sn-footer">` بنفس الشكل — عدّل في صفحة واحدة وانسخ إلى البقية، أو اطلب تعديلاً آلياً.
